# Project Constitution

## Principles

### Clear Contributor Feedback

Automated checks should provide direct, actionable pass/fail feedback before changes are merged.

### Reproducible Rust Validation

Rust quality checks should use the repository toolchain and locked dependency resolution where practical.

### Dependency Policy Enforcement

Dependency advisories, license rules, and dependency bans should be enforced by the repository's checked-in policy configuration.

## Governance

Changes that affect contributor workflow should be documented through specifications, plans, and task lists when requested.
